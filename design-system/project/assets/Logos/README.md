# Logos

The Raffaello mark: a white Roman capital R (Cinzel 800) in a dark red (#8E1B22) diamond with a gold (#E3AE12) bar, on an ink (#151213) tile. Used for the app icon, installer bitmaps and the header brand. Keep the ink tile; never recolour the diamond. The app's own masters are the SVG/ICO files in the Raffaello source (Assets/); this copy renders the R with a serif fallback if Cinzel is not installed.
